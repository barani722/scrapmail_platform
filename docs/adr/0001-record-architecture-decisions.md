# 1. Record architecture decisions

- Status: Accepted
- Date: 2026-11-11

## Context

The project is developed over several milestones by the project owner with AI
assistance. Decisions and their reasons must stay visible to everyone working
on the code later.

## Decision

Significant technical decisions are recorded as short Architecture Decision
Records in `docs/adr/`, numbered sequentially (`NNNN-title.md`), with the
sections Context, Decision and Consequences. A superseded record is kept and
marked "Superseded by NNNN".

## Consequences

- New contributors can understand why the system looks the way it does.
- Changing a recorded decision requires a new record, not a silent edit.
